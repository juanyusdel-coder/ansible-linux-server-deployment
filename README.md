# Ansible Linux Server Deployment

## Overview

This project demonstrates Linux server automation using Ansible.

The playbook automates:

- System updates
- Common package installation
- Docker installation
- Nginx installation

## Technologies

- Ansible
- Linux
- GitHub Actions
- Automation

## CI Pipeline

The GitHub Actions workflow automatically performs:

- Ansible syntax validation
- Playbook verification

- Infrastructure Automation
- Configuration Management
- Linux Administration
